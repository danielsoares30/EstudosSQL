# 📚 Estudos SQL Server

Repositório dedicado à minha jornada de estudos em **SQL Server**, com foco em **Database Administration (DBA)**, **T-SQL**, **Performance**, **Segurança**, **Backup & Restore**, **Alta Disponibilidade** e **Data Analytics**.

## 🎯 Objetivo

Documentar de forma prática minha evolução no SQL Server através de:

- Exercícios práticos
- Scripts SQL
- Laboratórios
- Desafios
- Projetos
- Documentação dos conceitos aprendidos
